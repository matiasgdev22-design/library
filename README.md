# Dev Library 📚

Una aplicación de biblioteca personal desarrollada con HTML, CSS y JavaScript.

Dev Library permite organizar libros, realizar un seguimiento del progreso de lectura y guardar notas personales en un solo lugar.

## Funcionalidades

- Agregar nuevos libros con título, autor, cantidad de páginas y categoría.
- Editar la información de los libros existentes.
- Eliminar libros de la biblioteca.
- Actualizar el estado de lectura: Pendiente, Leyendo y Terminado.
- Filtrar libros por estado de lectura y categoría.
- Buscar libros por título o autor.
- Agregar imágenes de portada mediante URL.
- Escribir y guardar notas personales para cada libro.
- Consultar estadísticas de la biblioteca.
- Guardar los datos utilizando Local Storage.
- Diseño adaptable a diferentes tamaños de pantalla.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage

## Cómo ejecutar el proyecto

1. Clonar este repositorio:

   ```bash
   git clone URL_DE_TU_REPOSITORIO
   ```

2. Ingresar a la carpeta del proyecto.
3. Abrir el archivo `index.html` en el navegador o utilizar la extensión Live Server de Visual Studio Code.
